# Sanggar Seni Campaka Arum

Website statis responsif untuk **Sanggar Seni Campaka Arum**.

## Upload ke GitHub

1. Buat repository baru di GitHub, misalnya `campaka-arum`.
2. Upload seluruh isi folder ini ke repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan. Website akan tersedia melalui GitHub Pages.

## Kustomisasi

- Edit teks dan alamat di `index.html`.
- Edit tampilan di `style.css`.
- Edit interaksi menu di `script.js`.
- Foto kegiatan dapat ditambahkan ke folder `assets` dan bagian galeri dapat diganti dengan gambar.
